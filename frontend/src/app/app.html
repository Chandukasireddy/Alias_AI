Alias AI is a local, transparent proxy for developers and enterprises. It intercepts API keys, customer PII, and industrial hardware secrets, replaces them with typed placeholders, and forwards only clean aliases to cloud models. Zero cloud leakage. 100% sovereign.

$ npx alias-ai start

How It Works

The local proxy sits transparently between your IDE/scripts and cloud LLM providers.

01

Local Intercept

Your app, Cursor IDE, or Python script calls http://127.0.0.1:8080/v1 using standard OpenAI protocol. No code refactor needed.

02

Extract & Alias

Local Gemma 2 and deterministic checksum rules strip sensitive VINs, IBANs, and API credentials into an in-memory AES-256 vault.

03

Egress Firewall

NVIDIA NeMo Guardrails mathematically verifies 0.00% private entropy leakage before the payload traverses TLS egress to the cloud.

04

Pass-Through Streaming

By default, tokens stream natively with <ALIAS_*> placeholders for maximum speed. Turn on --rehydrate to swap real secrets back locally.

CLI Command Reference

Command-line interface flags for the local proxy.

Command / Flag Default Description
alias-ai start - Launches the local transparent proxy daemon on your machine.
--port, -p 8080 Port for the local OpenAI-compatible HTTP proxy.
--target, -t nvidia-nim Upstream cloud LLM target endpoint (NVIDIA NIM, OpenAI, Anthropic).
--rehydrate, -r false Enable local re-hydration of placeholders back to real secrets. (Off by default for maximum streaming speed).
--model, -m gemma2 Local edge model for semantic extraction (Ollama Gemma 2 or built-in fast rule engine).
alias-ai doctor - Runs environmental healthcheck on local ports, Ollama, and Gemma 2.
