Zero-Knowledge Local Privacy Airgap Gateway

Airgap your LLM calls

Alias AI is a zero-dependency local proxy for developers, terminal agents, and enterprise workflows. It intercepts VINs, German IBANs, customer PII, and API keys, replaces them with typed placeholders, and forwards clean aliases to cloud models. Zero cloud leakage. 100% sovereign.

$ npx alias-ai start
✓ Pure Node.js (Zero Runtime Dependencies) ✓ 0.00% Private Entropy Leakage Proof ✓ Local Gemma 2 NER & Regex Enclave ✓ Pass-Through Streaming by Default

How It Works

The local proxy sits transparently between your IDE, terminal agent, or script and cloud LLM providers.

01

Local Intercept

Your app, Cursor IDE, or terminal agent calls http://127.0.0.1:8080/v1 using standard OpenAI protocol. No code refactor needed.

02

Extract & Alias

Local Google Gemma 2 (2B) and deterministic regex isolate sensitive VINs, German IBANs, and API credentials into an in-memory RAM vault.

03

Egress Firewall

The egress firewall mathematically verifies 0.00% private entropy leakage before the payload traverses TLS egress to cloud reasoners.

04

Pass-Through Streaming

Tokens stream at maximum frontier model speed with <ALIAS_*> placeholders intact. Optional -r flag re-hydrates locally.

CLI Command & Slash Command Reference

Command-line flags and interactive session shortcuts.

Command / Flag Type Description
alias-ai Command Launches the interactive agy-style terminal chat session.
alias-ai start Daemon Runs the local transparent proxy gateway on http://127.0.0.1:8080.
alias-ai doctor Diagnostic Runs local health checks: Node version, port 8080, Ollama daemon, and Gemma 2.
alias-ai test Self-Test Validates 0.00% private entropy leakage across 5 synthetic test suites.
alias-ai sanitize "<text>" Inspector Offline inspection showing exactly what the cloud sees vs what stays local.
alias-ai config Helper Prints ready-to-use configuration blocks for Cursor, Python, and shell.
--rehydrate, -r Option Enables client-side replacement of placeholders back into real secrets.
--port, -p <port> Option Port to bind local proxy (default: 8080, auto-increments to 8081 if occupied).
/vault, /v Chat Slash Inspect active RAM secrets in current interactive session.
/rehydrate, /r Chat Slash Toggle local re-hydration mode ON/OFF on the fly.
/clear, /c Chat Slash Flush the ephemeral session vault and wipe secret memory.
/exit, /q Chat Slash Safely exit interactive chat session.
